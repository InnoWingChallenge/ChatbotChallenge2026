抽查并要求修正后导出。没有调用项目 API，没有执行 embedding 或更新 Chroma。

## 使用哪个文件

- `records.json`：140 条新增片段，字段兼容现有图片入库记录结构。
- `sources.json`：新增片段的原图、描述、网页上下文和模型来源。
- `merged_records.json` / `merged_sources.json`：保留原有数据后的完整图片证据集合。
- `decisions.json`：357 张图片的处理决定、理由和保留句子的原始字段/索引。
- `needs_review.json`：104 张暂缓记录，不进入本次检索数据。
- `report.json`：数量、模型、输入和交付文件哈希、校验范围。

**当前项目的 `index_chroma` 会删除同一 pipeline 下未出现在输入集合中的记录，
因此不要把仅含新增数据的 `records.json` 单独传给它。** 后续入库应使用合并集合，
并先确认原有证据自本次快照起没有变化；本次没有替换项目正在使用的 records/sources。
合并集合只涉及图片证据，不代表将网页文字库清空或替换。

## 处理内容与边界

移除了或暂缓了人物杂项、低价值活动场景、可疑数量、模糊身份、
与设施归属无关的项目/产品图等。保留的句子直接引用原描述，不补写设备规格。
激光设备网页 caption 与此前看图记录的 Metal Laser 标签冲突已列入待核查。
原 GPT-5-mini / Luna 描述、模型与 prompt 版本继续保留。

这是文字层整理，**不是逐张重新看图，也不是事实全部正确的保证**。
新片段均标记 `text_curated_not_visual_verified`，不建立当前库存或地点断言。
关联正文仅覆盖能精确匹配来源 URL 的图片；长网页选择相关部分阅读，
旧证据比较使用候选匹配，不保证找尽跨视角、不同措辞的重复或全部冲突。
尚未运行入库后 RAG benchmark，不能声称准确率已经提升。

原图与完整原始描述继续位于项目原路径；数据包没有重复打包图片。
完整输入与执行过程见上级目录。68 项测试通过；导出校验通过。
